Yesterday a vector already in the span added nothing to it. Today's question is how to tell, for any list of vectors, whether one of them is spare in that way. It comes now because tomorrow's basis needs a spanning set with no spare vectors, so you need a test for spare vectors first. A set of vectors is independent when none of them is redundant, and the test asks whether some weights other than zero can combine the vectors into $\mathbf 0$.

## The definition

Day 1's target $\pink{\mathbf b} = (5, 6)$ equals $2\yellow{\mathbf v} + \blue{\mathbf w}$. If you walk along $2\yellow{\mathbf v}$, then $\blue{\mathbf w}$, then $-\pink{\mathbf b}$, you end where you started. That closed loop is the equation $2\yellow{\mathbf v} + \blue{\mathbf w} - \pink{\mathbf b} = \mathbf 0$.

<Definition term="Linear independence">
A set $\{\mathbf v_1, \dots, \mathbf v_p\}$ is **linearly independent** when the equation

$$
c_1 \mathbf v_1 + c_2 \mathbf v_2 + \cdots + c_p \mathbf v_p = \mathbf 0
$$

has only the **trivial solution** $c_1 = \cdots = c_p = 0$. The set is **linearly dependent** when some weights, not all zero, satisfy it. Such an equation is a **linear dependence relation**.
</Definition>
</Pair>

Every set has the trivial solution, because zero weights always give $\mathbf 0$. So the question is never whether the trivial solution exists. The question is whether it is the *only* one.

## A redundant vector

A dependence relation can always be solved for a vector whose weight is not zero. From $2\yellow{\mathbf v} + \blue{\mathbf w} - \pink{\mathbf b} = \mathbf 0$ you get $\pink{\mathbf b} = 2\yellow{\mathbf v} + \blue{\mathbf w}$. In the other direction, if one vector is a combination of the others, moving it across the equals sign with weight $-1$ gives a relation. This is Lay's Theorem 7: **a set of two or more vectors is dependent exactly when one of its vectors is a combination of the others.**

The theorem does not say that *every* vector in a dependent set is a combination of the others. In $\{\mathbf e_1, 2\mathbf e_1, \mathbf e_2\}$ the first two vectors are dependent, but $\mathbf e_2$ is not a combination of them.

While $\pink{\mathbf w}$ sticks out, the three arrows build a box with real volume. When $\pink{\mathbf w}$ drops into the plane, the box goes flat. ## The pivot test

Checking every vector against the others by hand gets slow, so the goal here is one row reduction that settles the whole set. The vector equation $x_1 \mathbf v_1 + \cdots + x_p \mathbf v_p = \mathbf 0$ is the system $A\mathbf x = \mathbf 0$, where $A = [\,\mathbf v_1\ \cdots\ \mathbf v_p\,]$. A nonzero solution exists exactly when the system has a free variable, and a variable is free exactly when its column has no pivot.

$$
\text{columns of } A \text{ are independent} \iff A \text{ has a pivot in every column}
$$

Yesterday's test for spanning counted pivots in every *row*. Today's test counts them in every *column*.

<Figure src="pivot-columns" alt="Three reduced matrices with orange boxes on their pivots. Top left, for h = 2, has a pivot in each of its three columns. Top right, for h = 0, has pivots only in columns one and two. Below them, the 2 by 3 matrix of v, w and b has two pivots and a third column without one." />

**Example.** Are $\yellow{\mathbf v_1} = (1, 2, 0)$, $\blue{\mathbf v_2} = (0, 1, 3)$ and $\pink{\mathbf v_3} = (2, 5, 3)$ independent?

$$
\begin{aligned}
\begin{bmatrix} 1 & 0 & 2 & 0 \\ 2 & 1 & 5 & 0 \\ 0 & 3 & 3 & 0 \end{bmatrix}
&\sim \begin{bmatrix} 1 & 0 & 2 & 0 \\ 0 & 1 & 1 & 0 \\ 0 & 3 & 3 & 0 \end{bmatrix}
\sim \begin{bmatrix} 1 & 0 & 2 & 0 \\ 0 & 1 & 1 & 0 \\ 0 & 0 & 0 & 0 \end{bmatrix}
\end{aligned}
$$

$$
\begin{aligned}
&x_1 = -2x_3, \quad x_2 = -x_3, \quad x_3 \text{ free} \\
&x_3 = -1: \quad 2\yellow{\mathbf v_1} + \blue{\mathbf v_2} - \pink{\mathbf v_3} = \mathbf 0
\end{aligned}
$$

Column three has no pivot, so the set is dependent. Substituting back checks the relation: $2(1, 2, 0) + (0, 1, 3) = (2, 5, 3)$.

## Deciding by inspection

Some sets can be decided without row reducing.

- **Two vectors** are dependent exactly when one is a multiple of the other, which means they lie on one line through the origin. Check every entry, since $(2, 4, 1)$ and $(1, 2, 3)$ agree in ratio for two entries and fail in the third.
- **A set containing $\mathbf 0$** is dependent, because $1 \cdot \mathbf 0 = \mathbf 0$ is a relation with a nonzero weight.
- **More vectors than entries** forces dependence. The matrix of $p$ vectors in $\mathbb R^n$ is $n \times p$. It has at most $n$ pivots, one per row, so when $p > n$ some column is free.

The last rule only works in one direction. Three vectors in $\mathbb R^3$ can be dependent or independent, and you have to check.

<LoopAnywhere v={[3, 1]} w={[1, 2]} start={[-2, 3]} goal={[1, -1]} />

The definition never mentions entries, so it works in any vector space. In $\mathbb P_1$, the polynomials $1$, $t$ and $3 + 2t$ are dependent, because $3 \cdot 1 + 2 \cdot t - (3 + 2t) = 0$ for every $t$.

Tomorrow a set that passes this test and also spans a space becomes a basis, which gives every vector in that space exactly one list of weights.
